# ระบบแจ้งเตือนวันหมดอายุใบประกอบวิชาชีพ (อบจ.อุบลราชธานี)

ระบบแจ้งเตือนอัตโนมัติผ่าน **LINE Official Account (`@855rhmoe`)** ด้วย **โปสต์การ์ดไฟล์รูปภาพ PNG ขนาด 1080 × 1080 px** แยกสีตามระดับความเร่งด่วน โดยรันอัตโนมัติฟรีทุกวันเวลา **08:00 น. (UTC+7)** ผ่าน **GitHub Actions**

## ระดับสีโปสต์การ์ดแจ้งเตือน (แจ้งซ้ำเดือนละ 1 ครั้ง)

เมื่อบุคลากรเข้าเกณฑ์ **ไม่เกิน 9 เดือน (≤ 270 วัน)** ระบบจะส่งโปสต์การ์ดแจ้งเตือน **เดือนละ 1 ครั้ง** (ไม่ส่งซ้ำภายในเดือนเดียวกัน) และเปลี่ยนสี + นับถอยหลังให้ตรงตามเวลาจริงทุกเดือนจนกว่าจะอัปเดตวันหมดอายุใหม่ใน `data/personnel.json`

| ช่วงเวลาคงเหลือ | สีสัญลักษณ์ | พฤติกรรมรายเดือน |
| :--- | :--- | :--- |
| **ระยะ 7–9 เดือน** (181–270 วัน) | 🟢 บัตรเขียว (`#176B4B`) | แจ้งเตือนเดือนละ 1 ครั้ง (9ด. → 8ด. → 7ด.) |
| **ระยะ 4–6 เดือน** (91–180 วัน) | 🟡 บัตรเหลือง (`#C98200`) | แจ้งเตือนเดือนละ 1 ครั้ง (6ด. → 5ด. → 4ด.) |
| **ไม่เกิน 3 เดือน** (0–90 วัน) | 🔴 บัตรแดง (`#B01E28`) | แจ้งเตือนเดือนละ 1 ครั้ง (3ด. → 2ด. → 1ด.) |
| **หมดอายุแล้ว** (< 0 วัน) | 🔴 บัตรแดงเข้ม (`#7D1018`) | แจ้งเตือนเดือนละ 1 ครั้งจนกว่าจะอัปเดตวันหมดอายุใหม่ |

## GitHub Actions Secrets ที่ต้องตั้งค่า

ไปที่ **Settings → Secrets and variables → Actions** และเพิ่ม 2 ค่า:
1. `LINE_CHANNEL_ACCESS_TOKEN` — Channel Access Token (long-lived) จาก LINE Developers Console
2. `LINE_GROUP_ID` — รหัสกลุ่ม LINE ที่เชิญบอท `@855rhmoe` เข้าไป

## การอัปเดตรายชื่อหรือวันหมดอายุ
แก้ไขไฟล์ `data/personnel.json` (ใส่วันหมดอายุรูปแบบ ค.ศ. `YYYY-MM-DD`) เมื่อมีการต่ออายุใบประกอบวิชาชีพและเปลี่ยนวันที่ใหม่ ระบบจะนับรอบแจ้งเตือนใหม่ให้อัตโนมัติ

## การทดสอบยิงภาพเข้ากลุ่ม LINE ด้วยตนเอง
1. ไปที่แท็บ **Actions** → เลือก **Daily EMS License Postcard Alert**
2. กด **Run workflow** แล้วเลือกโหมด:
   - `test_red` — ยิงภาพทดสอบสีแดง 1 ใบ (ไม่บันทึกทับ `sent_log.json`)
   - `test_all_colors` — ยิงภาพทดสอบครบทั้ง 3 สี (เขียว / เหลือง / แดง)
   - `check` — ตรวจและยิงแจ้งเตือนตามวันที่จริงวันนี้
   - `dry_run` — จำลองตรวจสอบโดยไม่ส่งเข้า LINE
